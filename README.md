# 🧠 Cypher AI - Search Algorithm Visualizer

🚀 A Python-based desktop application built using Tkinter that demonstrates and compares different AI search algorithms through interactive games like Tic-Tac-Toe and the 15-Puzzle.

---

## 📌 Project Overview

**Cypher AI** is designed to visualize how various search algorithms work in real-time.  
It provides a hands-on understanding of:

- State space exploration  
- Algorithm efficiency  
- Heuristic optimization  

---

## 🎮 Features

### 🔹 Tic-Tac-Toe (AI Powered)
- Minimax Algorithm (Perfect AI)
- Alpha-Beta Pruning (Optimization)
- Intelligent decision-making visualization

---

### 🔹 15-Puzzle Solver
- BFS (Breadth-First Search)
- DFS (Depth-First Search)
- A* Search Algorithm:
  - h1: Misplaced Tiles
  - h2: Manhattan Distance
