# AI Project — 15-Puzzle & Tic Tac Toe

## Project Structure

```
AI_Project/
├── main.py                  ← Entry point (run this)
├── read.md
├── algorithms/
│   ├── __init__.py
│   ├── astar.py             ← A* with h1 (misplaced) & h2 (Manhattan)
│   ├── bfs.py               ← Breadth-First Search
│   ├── dfs.py               ← Depth-Limited DFS
│   └── minimax.py           ← Minimax + Alpha-Beta Pruning
├── gui/
│   ├── __init__.py
│   ├── menu.py              ← Main menu
│   ├── puzzle_gui.py        ← 15-Puzzle Tkinter GUI
│   └── tictactoe_gui.py     ← Tic Tac Toe Tkinter GUI
├── models/
│   ├── __init__.py
│   ├── puzzle.py            ← Puzzle state, generation, neighbors
│   └── tictactoe.py         ← Board logic, win detection
└── utils/
    └── main.py              ← Alternative entry point
```

## How to Run

```bash
cd AI_Project
python main.py
```

Requires Python 3.x — no extra libraries needed (tkinter is built-in).

---

## Task 1: 15-Puzzle

- Random puzzle generated by making **30 shuffled moves** from goal state (guaranteed solvable)
- Click tiles manually to move them
- **Solve** button runs selected algorithm and animates the solution
- **Run All & Compare** runs all 4 algorithms and shows a comparison table

### Algorithms

| Algorithm | Strategy | Finds Optimal? |
|-----------|----------|----------------|
| BFS | Level-by-level | ✔ Yes |
| DFS | Depth-limited (limit=40) | ✘ Not always |
| A* h1 | Misplaced tiles heuristic | ✔ Yes |
| A* h2 | Manhattan distance heuristic | ✔ Yes (fastest) |

## Task 2: Tic Tac Toe

- You play as **X**, AI plays as **O**
- AI uses **Minimax with Alpha-Beta Pruning** — it never loses
- Score tracker across multiple games
- "AI First" button lets AI make the first move

### Minimax Scoring
- AI wins → `+10 - depth` (prefers faster wins)
- Human wins → `-10 + depth`
- Draw → `0`
